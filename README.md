 StreetChess - Ultimate Chess & Academy

StreetChess is a feature-packed, high-contrast, mobile-first web chess application built with a street-style neon urban design. It features an intelligent AI engine with selectable levels up to Grandmaster (Magnus Carlsen tier), an interactive Openings & Defenses Academy, Local Pass & Play, and WebRTC Peer-to-Peer LAN multiplayer.

✨ Features

🤖 AI Opponent (10 Levels up to 3000 ELO): Play against an adaptive chess engine powered by Minimax search with Alpha-Beta Pruning and custom Piece-Square Tables (PST). Level 10 simulates Magnus Carlsen's playstyle.

🎓 Openings & Defenses Academy: Interactive step-by-step training for top White openings (Ruy Lopez, Italian Game, Queen's Gambit, London System, English) and Black defenses (Sicilian Najdorf, French, Caro-Kann, King's Indian, Slav).

👥 Multiplayer Modes:

Local Pass & Play: Play face-to-face on the same screen with dynamic board rotation.

Friends / LAN (P2P): Direct peer-to-peer connection using WebRTC room codes over local Wi-Fi or internet.

🔍 High-Contrast Bold Vectors: Ultra-crisp, custom SVG piece vectors with glowing neon outlines designed for high legibility on smartphone screens and desktop displays.

📱 Mobile-First & Touch Optimized: Flexible viewports, safe-area inset support for mobile screens, and haptic feedback triggers for tap-to-move interactions.

🔊 Web Audio Synthesizer: Native retro sound effects generated via Web Audio API without external audio file assets.

📜 PGN Notation Log & Analysis: Live evaluation bar, move notation log, piece capture tracking, and PGN export support.

🚀 Quick Start / Live Demo

Since StreetChess is built as a self-contained web application, you can run it directly in any browser:

Clone or download this repository.

Open index.html in your favorite modern browser (Chrome, Edge, Firefox, Safari).

Host Free on GitHub Pages:

Go to your repository Settings on GitHub.

Select Pages from the sidebar.

Under Branch, choose main and root /, then click Save.

Your game will be live at https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/.

🛠️ Built With

HTML5 & CSS3: Responsive CSS Grid and Flexbox layouts.

Tailwind CSS: Modern utility-first styling.

JavaScript (ES6+): Custom game state controller and AI minimax algorithms.

Chess.js: Move generation, check/checkmate detection, and board state verification.

PeerJS: WebRTC peer-to-peer multi-device connection management.

FontAwesome: Scalable vector icons.
